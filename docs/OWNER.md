# Что потребуется от владельца

Код пишут агенты (Claude). Владелец принимает решения, тестирует на телефоне и даёт данные о себе.

## Один раз в начале

1. **GitHub.** Создать приватный репозиторий и подключить его к сессиям Claude Code. Это нужно, чтобы работа сохранялась: облачная сессия временная.
2. **Телефон Galaxy S25.** Включить «Режим разработчика» и «Отладку по USB».
3. **ПК.** Установить Android Studio. Через него ставится и обновляется APK, смотрятся логи и делается `adb push` моделей. Писать в нём код не обязательно. Как вариант, можно просто скачивать APK из GitHub Actions и ставить вручную.
4. **Сервер.** Сообщить характеристики: GPU и видеопамять, ОЗУ, диск, ОС. Установить Docker и Tailscale или WireGuard по инструкции из P5-01.

## Регулярно

- **Тестировать сборки на телефоне** и описывать, что не так. Скриншот или лог — идеально, своими словами — тоже нормально.
- **Ревьюить PR**, хотя бы по описанию: «что сделано и как проверить».
- **Решения:** имя ассистента, слово активации, карты, голос TTS, приоритеты.
- **Данные для персонализации:**
  - записи своего голоса (30–50 фраз в начале, дальше накапливаются сами);
  - исправления неверных расшифровок;
  - оценки ответов (👍/👎).
- **Запуск дообучения** на ПК или сервере (одна команда или по расписанию после P9-06).

## Kotlin

Учить заранее не нужно. Код будет с пояснениями, а в каждом PR будет раздел «как это устроено». Чтобы читать уверенно, достаточно бегло пройти Kotlin Koans (пара вечеров).
