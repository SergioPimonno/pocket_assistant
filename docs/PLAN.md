# План разработки

Статусы: `todo` · `in-progress` · `review` · `done` · `blocked`. Правила работы с задачами — в `/CLAUDE.md`.
Колонка «Зав.» — от каких задач зависит эта.
👤 — нужно действие владельца.

## Потоки для параллельной работы агентов

После этапа 0, когда интерфейсы зафиксированы, работа идёт параллельно в шести потоках:

| Поток | Область | Этапы |
|---|---|---|
| **A · Android-ядро** | UI, сервисы, оркестратор, роутер | 1, 3, 5 (клиент) |
| **B · On-device ML** | llama.cpp, sherpa-onnx, производительность, NPU | 0, 1, 3, 10 |
| **C · Секретарь** | инструменты, интенты, карты | 2 |
| **D · Сервер** | gateway, LLM, поиск, маршруты | 5, 6, 7 |
| **E · Персонализация и обучение** | память, профиль, LoRA, STT | 4, 9 |
| **F · Качество** | eval-наборы, регрессии, CI | все |
