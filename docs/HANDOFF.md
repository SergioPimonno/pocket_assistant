## Владелец

- Программист, Kotlin не знает. Общение на русском. ОС для разработки — Windows (Git Bash, PowerShell).
- Хочет править код руками. Работа ведётся **локально** в папке `development-pocket-assistant`, GitHub (`SergioPimonno/pocket_assistant`) — для контроля версий.
- Ограничен лимитами использования: одна задача — одна сессия. Без долгих исследований «на всякий случай».
- Приоритет — повседневный мини-секретарь. Онлайн — глубокий, гибкий поиск с проверкой фактов и разумными уточнениями.

## Железо

| Что | Статус |
|---|---|
| Телефон | **Пока нет.** Планируется Galaxy S25 (iPhone отвергнут, ADR-001). Разработка в эмуляторе (ADR-010) |
| ПК/ноутбук для разработки | Хороший CPU, слабая GPU. Точные характеристики не присланы |
| `dxv` (VPS) | 1,9 ГБ RAM, без GPU, занят сайтами владельца. Не использовать (ADR-008) |
| Рабочие серверы | Threadripper, A5000 + A4500. Только временно, для дообучения (ADR-009). Владелец сам согласует использование |
| Постоянный сервер | Не куплен. Цель — профиль `mid`: 4–8 vCPU / 16 ГБ (ADR-011). Регион выбрать пробой P5-01a. Рассматриваются VDSina, Raspberry Pi 5, б/у мини-ПК. Нужен только к M3 |

Справка по VDSina (ноябрь 2026):
- Standard — 4 ядра / 8 ГБ / 150 ГБ, 2 400 ₽;
- Hi-CPU 8 — 8 / 16 ГБ, 7 680 ₽;
- Dedicated 1 — 8 ядер / 30 ГБ, 9 870 ₽;
- GPU-тарифы — vGPU с 2–8 ГБ, невыгодно.

Оплата посуточная, локации — Москва и Амстердам.
